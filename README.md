# Political and Social Media Visualization

### Lola Coker
MS Data Science Candidate | Drexel University

## Overview
This project explores relationships between political identity, social media usage, and online political content using survey data from Pew Research.

## Tools Used
- Tableau
- Data Visualization
- Exploratory Data Analysis

## Key Findings
- Facebook users reported the highest daily usage frequency
- TikTok was perceived as the most politically neutral platform
- Instagram was perceived as the most liberal-leaning platform
- Political posting frequency varied across platforms and party affiliation

## Skills Demonstrated
- Dashboard design
- Data storytelling
- Comparative visualization
- Survey data interpretation
- Communication of insights
